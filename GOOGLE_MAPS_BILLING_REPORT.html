Security Issues & Risks

⚠️ CRITICAL SECURITY RISK
Your Google Maps API key is exposed in source code: lib/const/google_map_key.dart

Exposure Points

  • Visible in GitHub repository
  • Embedded in APK/IPA files
  • Accessible via reverse engineering
  • Can be accessed from browser network tab (Web)

Current Risk Level: HIGH

Anyone who extracts your key can:

  • Use Google Maps on their own projects
  • Drain your entire monthly quota
  • Incur massive billing charges
  • Abuse your API requests

Remediation Steps

Immediate Actions (Next 24 Hours)

  1. Regenerate API Key: Create new key in GCP Console
  2. Delete Old Key: Remove exposed key from GCP
  3. Set Restrictions: Limit new key to Android/iOS only
  4. Remove from Code: Delete from all source files
  5. GitIgnore: Add file to .gitignore

Implementation Options

Option A: API Key Restrictions (Quickest)

Restrict key usage in GCP Console:

  • Set Android app restrictions with SHA-1 fingerprint
  • Set iOS app restrictions with Bundle ID
  • Limit to specific domains for Web
  • Enable API-specific restrictions

Option B: Firebase Remote Config (Recommended)

Store API key in Firebase instead of code:

1. Create Firebase project
2. Set Remote Config parameter
3. Fetch key at app launch
4. Update code to use remote value

Option C: Backend Server (Most Secure)

Proxy API requests through your backend:

App → Your Backend → Google Maps API
